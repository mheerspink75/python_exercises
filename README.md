# Python Exercises & Worksheets

A structured collection of hands-on Python exercises, worksheets, and activity notebooks covering core Python concepts from syntax and data structures to object-oriented programming and standard libraries.

---

## 📚 Course Curriculum & Modules

### 🔹 Module 1: Python Basics & Syntax
Foundational concepts of programming with Python.
* **M1-Lesson01-Worksheets**
  * `Worksheet-Lesson 1A - Python Syntax.ipynb` — Python structure, comments, indentation
  * `Worksheet-Lesson 1B - Variables.ipynb` — Data types, variable assignments, and naming rules
  * `Worksheet-Lesson 1C - User Input.ipynb` — Receiving user input and type conversions
  * `Worksheet-Lesson 1 Activities.ipynb` — Practice exercises for Lesson 1

---

### 🔹 Module 2: Data Structures & Control Flow
Working with collections, iteration, and conditional logic.
* **M2-Lesson01-Worksheets (Lists & Tuples)**
  * `Worksheet 1A - Lists and List Operations.ipynb` — List indexing, slicing, methods, modifications
  * `Worksheet 1B - Tuples and Tuple Operations.ipynb` — Tuple creation, immutability, operations
  * `Lesson 1 Activities.ipynb` — Practice activities on sequences
* **M2-Lesson02-Worksheets (Loops & Iteration)**
  * `Worksheet 2A - For Loops.ipynb` — Iterating through collections
  * `Worksheet 2B - Searching Collections.ipynb` — Finding and validating elements
  * `Worksheet 2C - The Range Function.ipynb` — Generating sequences of numbers with `range()`
  * `Worksheet 2D - While Loops.ipynb` — Condition-controlled loops
  * `Lesson 2 Activities.ipynb` — Practice activities on loops and search algorithms
* **M2-Lesson03-Worksheets (Dictionaries & Sets)**
  * `Worksheet 3A - Dictionaries.ipynb` — Key-value pairs, dictionary methods, iterating dicts
  * `Worksheet 3B - Sets.ipynb` — Unique elements, set operations (union, intersection, difference)
  * `Lesson 3 Activities.ipynb` — Practice activities on associative collections

---

### 🔹 Module 3: Functions & Object-Oriented Programming (OOP)

* **M3-Lesson01-Worksheets (Functions)**

### 🔹 Module 4: Standard Library & Advanced Utilities
Exploring built-in modules, date-time handling, and iteration protocols.

## 🚀 Getting Started

### Prerequisites
* Python 3.8+
* Jupyter Notebook / JupyterLab or VS Code with the Jupyter extension

### Running the Notebooks Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/mheerspink75/python_exercises.git
   cd python_exercises
   ```
2. (Optional) Create and activate a virtual environment:
   ```bash
   python -m venv .venv
   # Windows (PowerShell):
   .venv\Scripts\Activate.ps1
   # Linux/macOS:
   source .venv/bin/activate
   ```
3. Install Jupyter:
   ```bash
   pip install jupyter notebook
   ```
4. Launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
